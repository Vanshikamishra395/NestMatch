# 📖 About The Project

NestMatch is an AI-powered rental platform that connects **property owners** with **tenants** through intelligent compatibility analysis.

Unlike traditional rental websites that simply list available rooms, NestMatch evaluates how well a property matches a tenant's preferences using **Google Gemini AI**, making the room-hunting experience smarter, faster, and more personalized.

The compatibility score is generated by analyzing:

- 📍 Preferred Location
- 💰 Budget
- 🏠 Room Type
- 🛋 Amenities

The platform then provides an easy-to-understand compatibility score along with AI-generated explanations.

# 🤖 AI Compatibility Scoring

NestMatch uses **Google Gemini AI** to intelligently evaluate how well a property matches a tenant's preferences.

Instead of simply displaying listings, the platform analyzes multiple factors and generates a personalized compatibility score.

### Parameters Considered

- 📍 Preferred Location
- 💰 Budget Range
- 🏠 Room Type
- 🛋 Amenities

The AI then returns:

- Compatibility Score (0–100)
- Match Summary
- Advantages (Pros)
- Things to Consider (Cons)

This enables tenants to make better rental decisions based on personalized recommendations.

---

# 🧠 LLM Prompt

The compatibility engine uses the following prompt structure:

```text
Given the following room listing:

Location:
Budget:
Room Type:
Amenities:

and the following tenant profile:

Preferred Location:
Budget Range:
Preferred Room Type:
Required Amenities:

Generate:

1. Compatibility Score (0-100)

2. Brief Summary

3. Advantages

4. Things to Consider

Return the response as JSON.
```
